# מבחן בקול (exam-reader)

אפליקציה לאייפד שעוזרת לתלמידה עם דיסלקציה להיבחן: כל שאלה מוקראת בקול, והיא עונה בהקלטה או בהכתבה.

**כתובת:** https://shiramnitentag-blip.github.io/exam-reader/

## מצב תלמידה
- המבחן הפעיל (רק אם המורה אישרה אותו). הקראה עם הקול המובנה של הדפדפן (`speechSynthesis`), נגיעה במשפט מקריאה אותו, שלוש מהירויות.
- תשובה בהקלטה (נשמרת ב-IndexedDB כל שנייה) או ב"לכתוב בקול" (הכתבה במקלדת האייפד). התשובות נשמרות לפי מבחן.
- עובד בלי אינטרנט אחרי פתיחה ראשונה (Service Worker).

## מצב מורה (🔒 במסך הפתיחה, קוד של 4 ספרות)
- הגדרות: מפתח Claude API (נשמר רק במכשיר, ב-IndexedDB) ובדיקת חיבור.
- העלאת מבחן: וורד (חילוץ טקסט עם mammoth), PDF או תמונות. Claude (`claude-sonnet-5-5`) מחזיר JSON לפי סכמה קבועה, מילה במילה. בוורד יש בדיקה אוטומטית שכל שאלה מופיעה במקור.
- ניקוד אופציונלי: נבדק שהמילים לא השתנו. שאלות שעלולות לחשוף תשובה מסומנות, והניקוד בהן כבוי.
- מסך בדיקה: עריכה, פיצול, איחוד, שינוי סוג, סדר, מחיקה, ניקוד והקראה לכל שאלה, ואישור.

## טבלאות ותמונות
- Claude מחזיר טבלאות כמבנה (כותרות ושורות, מילה במילה). אצל התלמידה: טבלה אמיתית מימין לשמאל, הקראה שורה אחר שורה עם שם העמודה, נגיעה בתא מקריאה אותו.
- תמונות (גרף, מפה, קריקטורה, צילום): מקובץ Word הן משויכות אוטומטית לשאלה. מ-PDF וצילומים המורה חותכת אותן בכלי "✂️ תמונה מהמקור" (PDF מוצג עם pdf.js). אפשר גם להעלות תמונה מהאייפד.
- התמונות נשמרות ב-IndexedDB ועובדות בלי אינטרנט. אצל התלמידה נגיעה בתמונה פותחת אותה במסך מלא עם הגדלה בצביטה. ההקראה מדלגת על תמונות ומקריאה רק את הכיתוב שמתחתן.

## קול איכותי (Azure) והכנה למבחן
- בהגדרות המורה: מפתח ואזור של Azure Speech, "בדיקת חיבור", בחירת קול בעברית ובאנגלית עם דוגמה. ברירת המחדל: he-IL-HilaNeural. המפתח נשמר רק במכשיר (IndexedDB), לעולם לא בקוד.
- "🎧 הכנה למבחן" יוצר מראש קובץ קול לכל משפט, אפשרות ותא בטבלה (REST עם SSML, קול לפי שפת המשפט) ושומר אותו ב-IndexedDB. "מוכן למבחן בלי אינטרנט" מופיע רק אם כל הקבצים נשמרו. כשמשהו נכשל רואים מה, ואפשר לנסות שוב.
- אצל התלמידה ההקראה מנגנת את הקבצים השמורים (מהירות דרך playbackRate). קובץ חסר → הקול המובנה של האייפד. "הקריאי לי מה כתבתי" ולחיצה ארוכה על מילה בודדת משתמשים בקול המובנה.
- שכבת `src/tts/` (ממשק `TTSProvider`) מאפשרת להוסיף שירותי קול נוספים בעתיד.

## ניקוד (דיקטה, ו-Claude כגיבוי)
- הניקוד נעשה קודם בנקדן של דיקטה (`src/dicta.ts`). לדיקטה אין API מתועד; מבנה הקריאה לקוח מהספרייה הפתוחה dicta-nakdan (MIT, github.com/moshejs/dicta-nakdan). הטקסט נשלח לשרת של דיקטה.
- אם דיקטה לא עונה (שגיאה, timeout של 20 שניות, או חסימת CORS), הקטעים שנשארו מנוקדים אוטומטית ב-Claude, והמורה רואה הודעה שהניקוד נעשה בשיטה החלופית (`src/nikud.ts`).
- במסך הבדיקה, נגיעה במילה מנוקדת מציגה ניקודים אפשריים (מדיקטה, או מ-Claude עם הסבר קצר כשדיקטה לא זמינה). בחירה משנה רק את הניקוד (האותיות של המבחן נשארות), וקובץ הקול של המשפט נוצר מחדש אוטומטית.

## עמידות ובדיקה לפני מבחן
- כל תשובה נשמרת מיד. הקלטה נשמרת בחלקים של שנייה, עם האורך עד כה; אם האפליקציה נסגרת, ההקלטה נשמרת עד אותה נקודה. מעבר לאפליקציה אחרת, כיבוי מסך או אובדן המיקרופון עוצרים את ההקלטה ושומרים אותה.
- השאלה הנוכחית נשמרת בשני מקומות (localStorage ו-IndexedDB), כך שפתיחה מחדש חוזרת לאותה שאלה עם כל התשובות.
- מצב מורה: אזהרה כשנשאר פחות מ-300MB פנויים, וכפתור "🩺 בדיקה לפני מבחן" (`src/teacher/PreExamCheck.tsx`): אישור, מבחן פעיל, קבצי קול, מיקרופון, מקום, תשובות ישנות, שם התלמידה, הגנה על הנתונים.
- כל כפתור בגודל 60 פיקסלים לפחות; ניגודיות לפי WCAG AA.
- מספר הגרסה (גרסה, תאריך בנייה ו-commit) מופיע בתחתית מסך ההגדרות.

### רשימת בדיקה ידנית באייפד לפני מבחן אמיתי
1. ההגדרות: מספר הגרסה הוא העדכני.
2. "🩺 בדיקה לפני מבחן" במבחן: הכול ✅. הסוללה מעל 50% או שהאייפד מחובר לחשמל.
3. מצב טיסה: לפתוח את האפליקציה ממסך הבית, "הקריאי" בשאלה הראשונה נשמע בקול של Azure.
4. הקלטה של 5 שניות ← עצירה ← "להשמיע": נשמע.
5. הקלטה ← יציאה למסך הבית באמצע ← חזרה: מופיעה הודעה שההקלטה נשמרה, והיא מתנגנת.
6. לסגור את האפליקציה לגמרי ולפתוח: חוזרת לאותה שאלה, התשובות במקומן.
7. "לכתוב בקול": להכתיב משפט, "הקריאי לי מה כתבתי".
8. לאפס את התשובות מהניסיון (מצב מורה ← "🔄 איפוס תשובות"), ולבדוק שוב ש"אין תשובות ישנות" ✅.
9. לצאת למצב תלמידה, ולהשאיר את האייפד על מסך הפתיחה של המבחן.

## תשובות (מצב מורה ← 📥 תשובות)
- רשימת המבחנים שנענו: שם התלמידה (מההגדרות, נשמר עם כל מבחן), תאריך, מצב (בתהליך / הוגש).
- לכל מבחן: כל שאלה עם הנוסח, התשובה בכתב, נגן לכל הקלטה, הבחירה בשאלה אמריקאית, או "לא נענתה".
- ייצוא שעובד גם בלי אינטרנט: קובץ PDF שנבנה במכשיר (`src/pdf.ts`, כל עמוד מצויר בדפדפן), הדפסה ישירה דרך `window.print()`, Word (ספריית `docx`, כל פסקה מימין לשמאל), ו-ZIP של ההקלטות (`fflate`).
- מחיקת התשובות וההקלטות של מבחן, עם אישור כפול.

## קבצים עיקריים
- `src/model.ts` מבנה המבחן. `src/claude.ts` הקריאות ל-Claude. `src/importer.ts` המרה ובדיקות.
- `src/student/` מסכי התלמידה. `src/teacher/` מסכי המורה. `src/db.ts` האחסון במכשיר.
- `src/report.ts` איסוף התשובות. `src/export.ts` וורד, ZIP ושיתוף.
- `src/speech.ts` ההקראה. `src/tts/` שירות הקול (Azure) וההכנה למבחן.

## לפיתוח
```
npm install
npm run dev
```
כל דחיפה לענף `main` (או לענף העבודה) בונה ומעלה את האתר אוטומטית ל-GitHub Pages.
