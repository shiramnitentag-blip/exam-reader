# מבחן בקול (exam-reader)

אפליקציה לאייפד שעוזרת לתלמידה עם דיסלקציה להיבחן: כל שאלה מוקראת בקול, והיא עונה בהקלטה או בהכתבה.

**כתובת:** https://shiramnitentag-blip.github.io/exam-reader/

## שלב 1 (מה יש עכשיו)
- מבחן לדוגמה קבוע בקוד (`src/exam.ts`), בטקסט מנוקד.
- הקראה עם הקול המובנה של הדפדפן (`speechSynthesis`), נגיעה במשפט מקריאה אותו, שלוש מהירויות.
- תשובה בהקלטה (נשמרת ב-IndexedDB כל שנייה) או ב"לכתוב בקול" (הכתבה במקלדת האייפד).
- עובד בלי אינטרנט אחרי פתיחה ראשונה (Service Worker), מבקש אחסון קבוע ו-Wake Lock.

## לפיתוח
```
npm install
npm run dev
```
כל דחיפה לענף `main` (או לענף העבודה) בונה ומעלה את האתר אוטומטית ל-GitHub Pages.
